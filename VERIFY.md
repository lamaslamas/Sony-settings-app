# Voci da verificare sulla fotocamera

Generato dai dati (`verify: true`). Stessa lista nell’app: Menu › “Voci da verificare”.

## Shooting

- [ ] **Image Quality/Rec › Lens Compensation › Shading Comp.** → `Auto` — _Base video · M1_. La specifica dice solo “Lens Compensation Auto”: applicato alle tre voci Shading / Chromatic Aberration / Distortion.
- [ ] **Image Quality/Rec › Lens Compensation › Chromatic Aberration Comp.** → `Auto` — _Base video · M1_
- [ ] **Image Quality/Rec › Lens Compensation › Distortion Comp.** → `Auto` — _Base video · M1_
- [ ] **Media › Rec. Media Settings › Recording Media (movie)** → `Simult. Recording` — _Base video · M1_. Nome esatto in guida: “Simult. Recording”. Valore scelto da verificare.
- [ ] **Audio Recording › Audio Rec Level** → `Manuale (livello numerico)` — _Base video · M1_. In guida Audio Rec Level è un livello numerico (+/−), non esiste un’opzione “Manual”. Regola il livello guardando i picchi.
- [ ] **Shooting Display › Emphasized REC Display** → `On` — _Base video · M1_
- [ ] **Image Quality/Rec › Image Quality Settings › File Format** → `RAW & JPEG` — _Base foto · M2_. Il “File Format” foto sta dentro Image Quality Settings; il “File Format” del menu è quello dei filmati.
- [ ] **Image Quality/Rec › Lens Compensation › Shading Comp.** → `Auto` — _Base foto · M2_. La specifica dice solo “Lens Compensation Auto”: applicato alle tre voci Shading / Chromatic Aberration / Distortion.
- [ ] **Image Quality/Rec › Lens Compensation › Chromatic Aberration Comp.** → `Auto` — _Base foto · M2_
- [ ] **Image Quality/Rec › Lens Compensation › Distortion Comp.** → `Auto` — _Base foto · M2_
- [ ] **Media › Rec. Media Settings › Recording Media (still image)** → `Simult. Recording` — _Base foto · M2_. Nome esatto in guida: “Simult. Recording”. Valore scelto da verificare.
- [ ] **Drive Mode › Drive Mode** → `Cont. Shooting: Lo` — _Base foto · M2_. Controlla come compare l’etichetta sul display.
- [ ] **Audio Recording › Audio Rec Level** → `Manuale, picchi ~−12 dB` — _Intervista · chiuso_. In guida è un livello numerico (+/−).
- [ ] **Audio Recording › Audio Rec Level** → `Manuale, picchi ~−12 dB` — _Intervista · aperto_. In guida è un livello numerico (+/−).
- [ ] **Drive Mode › Drive Mode** → `Cont. Shooting: Hi` — _Wildlife · aperto_
- [ ] **Image Quality/Rec › Image Quality Settings › File Format** — _Menu_. Opzioni elencate dal catalogo guida; controlla sulla fotocamera.
- [ ] **Image Quality/Rec › Image Quality Settings › JPEG Quality** — _Menu_
- [ ] **Image Quality/Rec › Movie Settings › Rec Frame Rate** — _Menu_. Valori disponibili variano con File Format/NTSC-PAL.
- [ ] **Drive Mode › Drive Mode** — _Menu_. La guida scrive “Continuous Shooting: Hi/Mid/Lo”; sul display l’etichetta è abbreviata. Controlla.
- [ ] **Shooting Mode › Memory/Recall Media** → `Slot (quello con la scheda delle basi)` — _Salva per l'evento (video)_. La specifica parla di “Select Media → Camera/Memory Card”: questa voce non esiste in guida. Qui si sceglie solo lo slot; camera vs scheda si decide scegliendo 1–3 oppure M1–M4 in Camera Set. Memory.
- [ ] **Shooting Mode › Memory/Recall Media** → `Slot (quello con la scheda delle basi)` — _Salva per l'evento (foto)_. Vedi nota sul video: in guida non esiste “Select Media”.
- [ ] **Scheda o camera: qui si sbaglia più facilmente** — _Guida_. La specifica descrive questo passaggio come Select Media → Memory Card / Camera, poi di nuovo Camera. Nella guida 4.00 della A7R V non esiste Select Media: c'è Memory/Recall Media (Slot 1 / Slot 2). Da provare sulla fotocamera.

## Exposure/Color

- [ ] **Color/Tone › D-Range Optimizer** → `Off` — _Base video · M1_. La specifica lo chiama “Dynamic Range Opt.”; il nome in guida è “D-Range Optimizer”.
- [ ] **Exposure › ISO Range Limit › Minimum** → `100` — _Base foto · M2_. La specifica dice “100–12800”: in guida ci sono Minimum e Maximum separati (anche in ISO › ISO AUTO Minimum/Maximum).
- [ ] **Exposure › ISO Range Limit › Maximum** → `12800` — _Base foto · M2_
- [ ] **Color/Tone › D-Range Optimizer** → `Auto` — _Base foto · M2_. La specifica lo chiama “Dynamic Range Opt.”; il nome in guida è “D-Range Optimizer”.
- [ ] **Zebra › Zebra Level** → `100+` — _Foto di gruppo · aperto_. Utile con sfondi chiari.
- [ ] **Zebra Display › Zebra Level** → `100+` — _Wildlife · aperto_. Livello per le alte luci: valore da verificare.
- [ ] **Zebra Display › Zebra Level** → `100+` — _Paesaggio_
- [ ] **Zebra › Zebra Level** → `100+` — _Paesaggio_. Livello per le alte luci da verificare.
